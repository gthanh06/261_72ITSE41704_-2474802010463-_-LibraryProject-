# Run guide — E-Library and Resource Circulation System

## 1. Requirements

| Software | Version | Notes |
|---|---|---|
| Windows | 10 or 11 | The application is a Windows Forms program. |
| .NET SDK | 8.0 | Included in Visual Studio 2022 17.8+ (".NET desktop development" workload). |
| SQL Server | Express 2019 or later | Default instance name `SQLEXPRESS`. LocalDB also works (see 3.2). |
| Visual Studio | 2022 (optional) | Or use the `dotnet` command line. |

Internet access is needed once, to download the NuGet packages (EF Core, ClosedXML, NUnit).

## 3. Configure the database connection

The connection string is in `src/ELibrary.WinForms/appsettings.json` (copied next to `ELibrary.exe` when building).

### 3.1 SQL Server Express (default)

```json
"ELibrary": "Server=.\\SQLEXPRESS;Database=ELibraryDb;Trusted_Connection=True;TrustServerCertificate=True"
```

### 3.2 LocalDB

```json
"ELibrary": "Server=(localdb)\\MSSQLLocalDB;Database=ELibraryDb;Trusted_Connection=True;TrustServerCertificate=True"
```

### 3.3 SQL login instead of Windows authentication

```json
"ELibrary": "Server=.\\SQLEXPRESS;Database=ELibraryDb;User Id=elibrary;Password=<password>;TrustServerCertificate=True"
```

You do **not** need to create the database: on the first start the application creates `ELibraryDb`,
its 17 tables, keys, indexes and check constraints, and fills it with sample data (about 15 seconds).

## 4. Build and run

**Visual Studio:** open `ELibrary.sln` → right-click **ELibrary.WinForms** → *Set as Startup Project* → **F5**.

**Command line:**

```
dotnet restore
dotnet build -c Release
dotnet run --project src/ELibrary.WinForms -c Release
```

Log in with one of the sample accounts (`admin / Admin@123`, `librarian1 / Librarian@123`,
`M0001 / Member@123` …).

## 5. Run the tests

**Visual Studio:** *Test → Run All Tests*. **Command line:** `dotnet test`

The tests do not need SQL Server: they use an in-memory unit of work and a fixed clock.

## 6. Sample data — what to try

The sample data is produced by running the real services over the past year, so every record obeys
the business rules. Dates are relative to the day the database was created.

| Try this | Account | Expected result |
|---|---|---|
| Check out to **M0005** | librarian1 | Refused (BR2): accrued fine on an overdue loan exceeds 50,000 VND |
| Check out to **M0007** | librarian1 | Refused (BR2): library card expired |
| Check out to **M0010** | librarian1 | Refused (BR2): unpaid fine above 50,000 VND |
| Fines of **M0009** | librarian1 | Partly paid fine; record the rest of the payment |
| Check out a copy to **M0001** twice more | librarian1 | Third item works, fourth is refused: "Loan limit reached (3/3)" (BR1) |
| Return **LIB0041** (Refactoring) | librarian1 | Copy goes on hold for M0003, the first in the queue (BR4, BR5) |
| Check out **LIB0081** to anyone but M0017 | librarian1 | Refused (BR6): copy is on hold for M0017 |
| Open **Holds** | librarian1 | The expired hold of M0019 has passed to M0020 (UC11) |
| Renew a loan of **M0002** | M0002 | Refused (BR7): members are waiting for the title |
| Reserve "Clean Code" | M0003 | Refused (BR4): a copy is available |
| Reports → Most-borrowed titles → Export | admin | Excel file with the ranking |

Copy barcodes follow the pattern `LIB` + title number (3 digits) + copy number, e.g. `LIB0011` is the
first copy of title 1 (Clean Code).

## 7. Generate the SQL script of the database

```
cd src/ELibrary.WinForms/bin/Release/net8.0-windows
ELibrary.exe --export-schema ..\..\..\..\..\docs\database\create_database.sql
```

The script is generated by EF Core from the mappings, so it always matches the code.

## 8. Backup and restore (NFR-08)

Log in as `admin` → *Administration → Settings, holidays and backup → Backup and restore*.
The backup path is a path on the computer that runs SQL Server; the folder must exist and the SQL
Server service account must be allowed to write to it (e.g. create `C:\ELibraryBackups` and give
*Everyone* write access for a lab PC). After a restore, restart the application.

## 9. Starting again with fresh sample data

Delete the database (SSMS: right-click `ELibraryDb` → *Delete*, tick *Close existing connections*)
and start the application again.

## 10. Notes for developers

* All windows are built in code (no `.Designer.cs` files). If Visual Studio opens a form in the
  designer, use **View Code (F7)** instead.
* Business rules live only in `ELibrary.Domain` and `ELibrary.Business`; screens just call services.
* Errors are logged to `%LOCALAPPDATA%\ELibrary\logs`.

## 11. Troubleshooting

| Problem | Cause and fix |
|---|---|
| "SQL Server cannot be reached" at start-up | SQL Server service not running (start *SQL Server (SQLEXPRESS)* in *services.msc*) or wrong instance name in `appsettings.json`. |
| "The database could not be prepared" | The Windows user has no permission to create databases — use an administrator account once, or a SQL login with `dbcreator`. |
| Backup fails with "Operating system error 5" | The SQL Server service cannot write to the folder — see section 8. |
| Unexpected error message | Details are written to `%LOCALAPPDATA%\ELibrary\logs\error-YYYYMMDD.log`. |
